# Employee Performance & Attrition Analysis Dashboard (Power BI)

## 📌 Project Overview
This project showcases an interactive **Employee Performance & Attrition Analysis Dashboard** developed using **Power BI**.  
The dashboard focuses on understanding workforce trends, employee performance, satisfaction levels, and factors contributing to attrition through data-driven analysis.

---

## 🎯 Objectives
- Analyze employee attrition patterns across departments and job roles
- Evaluate employee performance, satisfaction, and work-life balance
- Identify factors influencing employee retention
- Enable exploratory analysis using interactive visualizations

---

## 📊 Key KPIs
- **Total Employees**
- **Attrition Rate (%)**
- **Average Performance Rating**
- **Average Work-Life Balance**
- **Average Years at Company**

---

## 📈 Dashboard Features
- Attrition analysis by **Department** and **Job Role**
- Work-Life Balance vs Attrition comparison
- Employee satisfaction analysis:
  - Environment Satisfaction
  - Job Satisfaction
  - Relationship Satisfaction
- Average work experience comparison by Attrition
- OverTime impact on Attrition
- Interactive filters for:
  - Gender
  - Department
  - Job Role
  - Marital Status
  - Business Travel Frequency

---

## 🛠 Tools & Technologies Used
- **Power BI**
- **DAX** (Measures & Calculations)
- **Data Visualization & Analytics**

---

## 📂 Dataset
- Employee Performance dataset containing:
  - Demographics
  - Job roles and departments
  - Performance ratings
  - Satisfaction metrics
  - Work-life balance
  - Attrition indicators

## 📌 Key Insights
- Attrition varies significantly across departments and job roles
- Lower work-life balance is associated with higher attrition
- Employee satisfaction metrics show a strong relationship with retention
- OverTime contributes to increased attrition likelihood

1. Download the `.pbix` file

3. Use slicers to explore trends and patterns
4. Extend or customize the dashboard as needed
